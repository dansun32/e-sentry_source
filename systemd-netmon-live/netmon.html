systemd D-Bus & IPAccounting Reference

1. Querying Systemd Units via D-Bus

Systemd exposes accounting metrics over the system D-Bus at object path /org/freedesktop/systemd1.

# Example using gdbus CLI tool:
gdbus call --system \
  --dest org.freedesktop.systemd1 \
  --object-path /org/freedesktop/systemd1/unit/ssh_2eservice \
  --method org.freedesktop.DBus.Properties.Get \
  "org.freedesktop.systemd1.Service" "IPIngressBytes"

2. Target Properties

  • IPIngressBytes (uint64): Total inbound byte counter.
  • IPEgressBytes (uint64): Total outbound byte counter.
  • IPIngressPackets / IPEgressPackets: Packet counter metrics.

3. Python D-Bus Snippet

import dbus

bus = dbus.SystemBus()
systemd = bus.get_object('org.freedesktop.systemd1', 
                         '/org/freedesktop/systemd1')
manager = dbus.Interface(systemd, 'org.freedesktop.systemd1.Manager')

# Get unit object path
unit_path = manager.GetUnit('ssh.service')
unit_obj = bus.get_object('org.freedesktop.systemd1', unit_path)
props = dbus.Interface(unit_obj, 'org.freedesktop.DBus.Properties')

ingress = props.Get('org.freedesktop.systemd1.Service', 'IPIngressBytes')
egress = props.Get('org.freedesktop.systemd1.Service', 'IPEgressBytes')
print(f"Ingress: {ingress} bytes | Egress: {egress} bytes")

4. Why Raw Sockets Bypass /etc/hosts.deny

Daemons like systemd-networkd, dhclient, or wpa_supplicant open raw AF_PACKET sockets to manage link-layer traffic or DHCP discovery. Because they interact directly with kernel network devices, they completely bypass application-layer wrappers such as /etc/hosts.deny (libwrap).
