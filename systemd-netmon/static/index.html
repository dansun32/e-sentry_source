                systemd IPAccounting & netmon reference
            

            
        

        

            

                
1. Where the numbers come from

                
The backend runs systemctl show -p IPIngressBytes,IPEgressBytes,... UNIT… each poll and divides the counter deltas by elapsed time. Counters exist only for units with IPAccounting=yes (BPF on the unit's cgroup); everything else is shown as n/a, never faked.

                
# enable until reboot (the row menu does this):
sudo systemctl set-property --runtime UNIT IPAccounting=yes
# permanently (drop-in):
sudo systemctl set-property UNIT IPAccounting=yes
# or for every service:
# /etc/systemd/system.conf -> DefaultIPAccounting=yes

            

            

                
2. Actions

                
    
                    
  • stop / start / restart: runtime only, survives nothing across reboot.
    • 
                    
  • kill: systemctl kill --signal=SIGTERM|SIGKILL on every process of the unit. A unit with Restart= may come straight back.
    • 
                    
  • disable: not started at boot (can still be pulled in by other units/sockets). mask: links the unit to /dev/null so nothing can start it. Undo with enable / unmask.
    • 
                    
  • Critical units (journald, dbus, logind, udevd, NetworkManager, display manager, polkit, PIA, firewall, ssh during an SSH session, this backend) are refused unless you type the override word.
    • 
                    
  • Every attempt is written to the audit log, including refusals and dry-runs.
    • 
                

            

            

                
3. Raw / packet sockets

                
Daemons like NetworkManager, dhclient, wpa_supplicant or tcpdump open AF_PACKET / SOCK_RAW sockets that bypass libwrap (/etc/hosts.deny). The kernel exposes no per-socket packet counters for them, so packet rate is n/a; the drops counter (raw) and Rmem (packet) are real. Socket owners are found by scanning /proc/*/fd, which needs root for other users' processes.
